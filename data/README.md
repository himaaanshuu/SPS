# Demo dataset

`placement_data.csv` is a **synthetic, clearly-labeled demo dataset** generated by
`backend/app/ml/dataset.py` (seed 42, n=1500 default). It is NOT real-world placement
statistics and must never be presented as such.

## Features
cgpa (0–10), tenth_pct, twelfth_pct, backlogs, coding_score, dsa_proficiency,
projects, certifications, quant_aptitude, logical_reasoning, verbal_ability,
communication, internship_months, interview_readiness, extracurricular, placed (0/1).

## Limitations
- Synthetic correlations are illustrative only.
- No department/package columns in v1.
- Replace with an institutional (anonymized) dataset for real evaluation.
