# Student Placement Prediction System Using Neuro-Fuzzy Soft Computing

A web-based placement intelligence product: predicts a student's **placement probability**,
**placement readiness**, and **skill gaps** from 15 academic / technical / aptitude /
communication / experience signals — using an interpretable **neuro-fuzzy soft computing** core.

> **Honesty contract:** demo data is synthetic and labeled as such; untrained models report
> "Awaiting training data" instead of fabricated metrics; the UI works offline with a
> clearly-labeled heuristic fallback.

## Features

- Student profile creation (minimal PII by design — no Aadhaar/phone/passwords)
- Placement probability + status (`LIKELY TO BE PLACED` / `BORDERLINE` / `NEEDS WORK`)
- Readiness score with 5-axis breakdown (academic, technical, aptitude, communication, experience)
- Fuzzy-logic explanation: linguistic membership values + fired rules with firing strengths
- Neural network visualization (15 → 32 → 16 → 8 → 1) with real metrics
- Model comparison across Logistic Regression / Random Forest / Neural Net / Fuzzy / Neuro-Fuzzy
- Skill-gap analysis with current-vs-target and a sequenced 4-week plan
- Prediction history (SQLite), analytics, admin oversight dashboard
- Distinct light ("premium education product") and dark ("AI research lab") themes, no gradients
- Subtle cursor-reactive "Placement Intelligence Network" canvas background

## Dataset

`backend/data/placement_data.csv` is **synthetic demo data** (seed 42, n=1500) generated by
`backend/app/ml/dataset.py`. See `data/README.md`. Replace with an anonymized institutional
dataset for real evaluation.

## Methodology (short)

- **Fuzzy logic:** CGPA/coding/communication fuzzified into LOW-MEDIUM-HIGH style linguistic
  terms (triangular/trapezoidal); 12-rule Mamdani base; min-inference; centroid defuzzification
  → `fuzzy_score` (0–100). See `backend/app/fuzzy/`.
- **Neural network:** 15 → 32 → 16 → 8 → 1, ReLU hidden, sigmoid output, binary cross-entropy,
  Adam, early stopping. Uses Keras when TensorFlow is installed, otherwise sklearn `MLPClassifier`
  with the same topology (the comparison table labels which backend was used).
- **Neuro-fuzzy:** 0.55 × RandomForest probability + 0.45 × fuzzy score, evaluated on the held-out
  test split like every other model.
- **Readiness:** 0.6 × mean(5-axis breakdown) + 0.4 × placement probability.

## Installation

```bash
# backend
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r ../requirements.txt
python -m uvicorn app.main:app --reload --port 8000   # run from backend/

# frontend (new terminal)
cd frontend
npm install
npm run dev        # http://localhost:5173
```

Train models (enables real metrics + neuro-fuzzy model; otherwise the API uses a labeled heuristic):

```bash
curl -X POST http://localhost:8000/api/train
```

## API documentation

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/health` | status + trained flag |
| POST | `/api/predict?model=neuro_fuzzy` | full prediction + explanation |
| POST | `/api/fuzzy-evaluate` | memberships + fired rules + fuzzy score |
| POST | `/api/model/predict?model=...` | raw model probability |
| GET | `/api/model/metrics` | honest metrics or "awaiting training" |
| POST | `/api/train` | train all models on CSV or demo data |
| GET | `/api/analytics` | cohort aggregates (labeled synthetic) |
| GET/POST | `/api/students`, GET `/api/students/{id}` | student records |
| GET | `/api/predictions` | prediction history |

Interactive docs: http://localhost:8000/docs
